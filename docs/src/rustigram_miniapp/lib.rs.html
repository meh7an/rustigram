1//! Server-side Telegram Mini App bridge for the rustigram framework.
2//!
3//! Provides initData validation, typed Axum extractors, a Tower middleware
4//! pipeline, and an optional ts-rs type generation pipeline so Rust structs
5//! stay in sync with the TypeScript `@rustigram/tma-*` packages.
6//!
7//! # Feature flags
8//!
9//! | Flag | Effect |
10//! |---|---|
11//! | `ts` | Enables ts-rs derives on all public types. Required for `gen-types`. |
12//!
13//! # Deployment modes
14//!
15//! ## Mode 1 — TypeScript only
16//!
17//! `@rustigram/tma-server` handles validation. No Rust backend required.
18//! `BOT_TOKEN` lives in the TypeScript environment.
19//!
20//! ## Mode 2 — Rust only
21//!
22//! Rust is the API server. `@rustigram/tma-server` is not used on the
23//! backend at all. `@rustigram/tma-core` still works on the frontend.
24//! `BOT_TOKEN` lives in the Rust environment only.
25//!
26//! ## Mode 3 — Rust gateway + SolidStart BFF
27//!
28//! Rust validates and signs forwarded requests. SolidStart parses without
29//! re-validating. `BOT_TOKEN` lives in Rust only. SolidStart only needs
30//! `GATEWAY_SECRET`.
31//!
32//! See [`extract::BotTokenLayer`], [`extract::TmaGatewayLayer`], and
33//! [`extract::TmaInitData`] for the full setup.
34//!
35//! # Quick start
36//!
37//! ```rust,ignore
38//! use axum::{routing::post, Router};
39//! use rustigram_miniapp::{
40//!     extract::TmaInitData, BotToken, BotTokenLayer,
41//!     GatewaySecret, TmaGatewayLayer,
42//! };
43//!
44//! async fn tma_handler(TmaInitData(data): TmaInitData) {
45//!     println!("user: {:?}", data.user);
46//! }
47//!
48//! // Mode 2 — Rust only
49//! let app = Router::new()
50//!     .route("/tma", post(tma_handler))
51//!     .layer(BotTokenLayer(BotToken(
52//!         std::env::var("BOT_TOKEN").unwrap(),
53//!     )));
54//!
55//! // Mode 3 — Rust gateway, add TmaGatewayLayer for the trust signal
56//! let app = Router::new()
57//!     .route("/tma", post(tma_handler))
58//!     .layer(TmaGatewayLayer(GatewaySecret(
59//!         std::env::var("GATEWAY_SECRET").unwrap(),
60//!     )))
61//!     .layer(BotTokenLayer(BotToken(
62//!         std::env::var("BOT_TOKEN").unwrap(),
63//!     )));
64//! ```
65//!
66//! # Security — Mini App origin restriction (Bot API 10.2)
67//!
68//! Telegram now disallows calling Mini App methods from an origin different
69//! from the Mini App's own domain. This protection is enforced client-side by
70//! Telegram and rolls out automatically to all Mini Apps on July 20, 2026 —
71//! opt-out is via @BotFather, not via this crate. It requires **no changes**
72//! in `rustigram-miniapp`: initData validation, the Axum extractors, and the
73//! gateway layer all operate on data Telegram has already validated against
74//! the registered domain, so there is nothing for this crate to additionally
75//! enforce. If you opted out via @BotFather, you are responsible for ensuring
76//! your Mini App has no links to untrusted sites.
