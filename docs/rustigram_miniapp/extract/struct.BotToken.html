Struct BotToken 

Source 
pub struct BotToken(pub String);
Expand description

Newtype wrapping the bot token string.

Injected into every request by BotTokenLayer and read by TmaInitData during extraction. Cloning is cheap — the Arc is inside if you need it, but for most bots a plain String is fine.
